# 全站优化复核：2026-10-14

本轮覆盖首页、博客筛选、学习路线、归档、分类、标签与文章阅读。原有文章 URL、章节 ID、发布日期和草稿状态保持不变。

## 导航与窄屏阅读

- 导航和页脚增加学习路线入口；学习路线介绍不再手写会过期的专题数量。
- 归档增加六个年份的跳转和文章计数；分类、标签及单个主题页面增加返回文章列表和学习路线的入口。
- 导航控件保留在同一行，并扩大到至少 40 CSS 像素的点击区域；长标签允许换行，避免计数徽标被挤出卡片。
- 缩小首页头像的装饰背景外沿，避免平板宽度下横向溢出。
- 两张实际过窄的表格启用已有 `table-readable` 样式：手眼标定的两条接口路径，以及 PPO/DPO/GRPO 实验的 CSV 字段说明。紧凑数值表没有统一加宽。
- 暗色主题的图号使用深色前景，提高与浅蓝底色的对比度。

## 键盘、主题和图片

- 关闭的手机菜单设为 `inert`；打开时隔离背景焦点并限制 Tab 范围。主题或语言子菜单处理 Escape 后，不会误关外层手机菜单；切换到桌面宽度会清理手机菜单状态。
- 主题菜单支持方向键、Home、End、Escape 和 Tab；选择后返回触发按钮。无法读写本地存储时，仍可切换当前页面的外观；跟随系统和跨标签偏好变更也会更新界面。
- 中文界面的外观选项使用中文标签。
- 可放大的图片提供原图链接：键盘 Enter 打开现有查看器，Escape 或 Tab 返回；关闭 JavaScript 后仍能打开原图。作者已有的图片超链接保留其原目标，避免嵌套链接。
- 图片链接使用已知尺寸预留空间，保留小图的原始宽度、SVG 的比例和原有懒加载。模板输出的 CSS 尺寸同时由夹具检查，防止尺寸被转义器丢弃而引起章节位置移动。
- 响应式图片的 `sizes` 对齐文章在手机、平板及双侧栏桌面的宽度，避免平板选图过小及高密度桌面过度加载原图。减少动画模式仍保留 1ms 过渡，因为现有查看器依靠 `transitionend` 完成打开和关闭。

## 本站资源与构建

KaTeX 0.16.21、FlexSearch 0.8.143、Medium Zoom 1.1.0 已固定为仓库资源。两个 JavaScript 文件与原网站加载的字节一致；KaTeX CSS 只保留 WOFF2 字体入口，20 个字体文件保持上游原始内容，并通过相对 URL 由本站提供。

版本、下载来源、归档及文件校验值见 [vendor-assets.json](vendor-assets.json)。上游许可证保留在资产目录，并发布至 `/licenses/`。配置修改位于 `config.yaml`；GitHub Pages 工作流增加图片夹具与 `test_site_assets.py`，检查图片尺寸／链接，以及文件完整性、字体、许可证发布和 SRI。主题子模块没有修改，模板和脚本均通过仓库覆盖实现。
