已特别复核：

1. RT-2 的贡献不写成机器人第一次利用图像、语言或动作 token；π0 不写成机器人第一次折叠衣物。
2. OpenVLA 的 16.5 为特定 RT-2-X 对照中的成功率百分点差，不是参数规模的独立因果结论。
3. 原始 OpenVLA 单张图像与语言输入，不自动继承后续 OFT 的多相机、本体状态与动作块设置。
4. 均匀量化算例使用 K 个等宽区间；固定版本 OpenVLA 的边界与中心实现单独说明，没有冒充逐行复现。
5. 单点 L2 的条件均值问题不推广成所有回归都不可用；L1 中位数可能不唯一，OFT 是连续回归的具体反例。
6. Flow Matching 按 openpi 的时间方向解释：s=1 为噪声，s=0 为数据，速度目标为噪声减数据，积分步长为负。更换时间参数必须一起更换符号。
7. 50 步动作、采样迭代次数、50 Hz 控制和实际执行前缀分开。预测覆盖时长与末个离散目标时间也分开。
8. π0 原始最大维度 18 与 openpi 默认 32 分属论文与代码配置；图像／语言前缀缓存和状态 suffix 的实现位置不混淆。
9. π0 数据小时数、903M 时间步、任务数、公开数据混合占比分属不同口径；0.43 次幂为论文的重采样设计。
10. π0.5 原始训练阶段、后来 KI 的梯度隔离与 openpi 的公开 flow-only 训练路径分别描述。
11. RECAP 使用价值与优势条件、迭代利用经验，不写成普通 PPO 或每个控制步都更新权重。
12. π0.7 的约 5B 是策略模型规模；独立视觉子目标模型、高层策略与运行缓存另计。
13. π0.7 的质量条件不是成功保证；生成目标不是评测真实未来；机器人—任务组合泛化不等于所有相关经验都未见。
14. π0.6／π0.7 研究报告的公开与指定 openpi 快照中的可下载模型类型分开说明。
15. 论文进度得分与整任务成功率分开；消融建议明确控制数据、预算、执行设置和人工介入。
