## 图片查看与代码阅读

此前线上诊断中，一张 1,063,236 字节的 SuperMimic 原图下载用了 9.09 秒。旧查看器等待原图后才完成打开，下载期间的关闭交互也会延迟。这是一次实际网络样例，不代表固定的访问耗时。

现在先显示已加载的响应式预览，再后台升级为原图。原图失败仍保留预览并提供原图入口，关闭后可重试；下载期间 Escape、关闭按钮与打印均可立即操作。原生 dialog 约束模态焦点，Tab 在原图链接与关闭按钮间循环，退出恢复文章焦点和滚动位置。缺少 JavaScript 或 dialog 支持时保留原生图片链接，作者自行链接的图片继续使用原链接。

查看器支持三种站点主题、小图片、短窗口、200% 字体及减少动态效果设置。打印关闭查看器并显示正文，待下载的原图不会阻塞打印流程。

SuperMimic 的第一块代码在放大字体后从可容纳变为横向溢出，但原代码只在初始加载和窗口 resize 时检查焦点。现在字体完成、代码尺寸变化、折叠内容开关都会触发批量测量，及时设置可滚动代码块的键盘入口。增加字距时还发现外框不变、内部文字变宽的情况，进一步纳入文章布局尺寸观察。原有复制内容与失败后的手动选择行为保留；补测了异步复制、重复按键和复制期间 Tab 离开的焦点行为。
