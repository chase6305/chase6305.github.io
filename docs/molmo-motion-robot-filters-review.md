## MolmoMotion 关键复核

1. 核心输出为物体点三维轨迹，不直接等同于关节动作、动力学模拟器或真实机器人闭环控制。
2. 固定参考系为最后历史时刻的相机系。所有点共享首个查询点的锚点，不能误写成每点减去自己的起点；高级输出已经还原锚点。
3. 区分历史长度、未来长度、输出索引、取帧策略、视频播放速度、模型推理耗时和机器人执行频率。
4. 毫米量化是编码分辨率，不能冒充毫米级预测精度。
5. 论文比较 AR 与 FM，但公开主模型是 AR。FM 的十次生成迭代每次更新整段轨迹，不是十个物理动作时刻。
6. 论文的局部二维点特征与发布配置分开：公开配置省略的字段默认值为 false，不能仅凭论文图认定该 checkpoint 启用。
7. 数据流水线区分视频完整信息用于离线标签与历史信息用于推理；图中保留已知查询点和语言条件。
8. 训练注册入口继承 `mixed_history=True`，配方名称不能直接证明每条样本都用同一历史长度。
9. 动态 packing 的 batch × steps 是打包序列数量，不是独立视频数。论文 batch／warmup 与公开脚本默认值分别列出。
10. 原始数据加载构造器在训练分支合并 train／test 条目；内部 test loss 不能自动视为独立留出结果。用未改写构造器和合成索引验证了重叠，轨迹文件筛选和评估展开仅用桩替代；没有加载全量数据。PointMotionBench 是另一条评估路径。
11. `initial_model_checkpoint` 分支重置训练器和优化器状态；初始化权重与完整断点恢复不同。
12. ADE 聚合、共同最终帧与逐点最后可见帧 FDE、PWT 阈值及边界约定分别说明。PWT 无单位，不是抓取成功率。
13. 主文 best-of-5、附录 greedy 与公开默认入口存在协议差异；重复确定性生成不能构造候选多样性。
14. `--all_points` 仍按完整八点组处理，默认还限制点数。Python `hash()` 参与种子计算，数值 seed 单独固定并不足够。
15. 实际汇总函数在空文件或无有效记录时可返回零指标；同步记录样本数。用合成 JSONL 调用了正常、空输入和形状不匹配三条路径。
16. 论文机器人策略重新训练连续动作头，生成／动作块／执行前缀分别为 10／16／8；原策略先抓取，再交给适配策略。DROID 部分是视频轨迹适配，不能写成真机闭环成功率。
17. 权重统计来自元数据；原生与 safetensors 格式、共享嵌入与转换后复制输出头分开。没有下载完整权重或测量 GPU 峰值显存。
18. 缓存预测 CPU 可视化路径实际完成 MP4 输出；没有重新运行神经网络。
19. 实际生成预算为 `160 × future_horizon`，函数旧说明仍写 48 倍；记录实际执行分支，并解释截断文本与形状检查的局限。
20. 论文消融小幅差值不附会显著性；提出按视频／对象配对重采样，避免把相关点帧当成独立试验。

## 滤波关键复核

1. 区分测量滤波、状态估计、参考平滑和运动约束，分类图表示可选功能位置，不要求全部串联。
2. WMA 的最新值权重、启动行为、相同值是否进入队列分别核对；本文实现与引用的 Unitree 版本差异明确注明。
3. EMA 的后向 Euler 与指数系数分开，群延迟的采样点／秒单位分开。按数字频响数值求解 200 Hz 采样、名义 5 Hz 时的 −3 dB 点，分别约 4.652／5.010 Hz；One Euro 自适应后的时变性质另行说明。
4. Butterworth 通带平坦不表示零相位或零超调；SOS 跨块保留状态。手写二阶系数采用预畸变并核对反馈符号。
5. `buttord` 按给定通阻带损失选阶，所得截止频率与通带边缘不同。
6. 前后向滤波改变幅频响应；居中 SG、Hampel、Wiener 和重采样接口不能直接冒充逐样本零延迟在线算法。
7. One Euro 采用作者固定 Python 版本的前一滤波值计算变化率；单位从米改成毫米时 β 相应缩小。
8. SO(3) 更新保持旋转几何；姿态自适应增益采用低通后的非负角速度尺度，不能等同于先低通角速度向量再取范数。
9. 新增耦合三轴旋转的固定世界／物体参考系等变性检查，避免只用单轴角度越界例子验证乘法顺序。
10. MSD 自然频率与截止频率不同，临界阻尼与 Butterworth 不同，非零初始速度下仍可能越过目标；平滑不提供硬速度／jerk 约束。
11. 精确 ZOH 的输入属于上一个保持区间，输出时间不提前标记。显式 Euler 连续稳定与离散稳定分开。
12. Kalman 的两类加速度过程噪声模型、单位转换、测量相关性和时变采样分开。
13. Kalibr 白噪声密度与偏置随机游走随 dt 的缩放相反；抗混叠假设不可省略。
14. EMA 后噪声有时间相关性，仅减小后续 Kalman 的 R 不足以表达已有滤波动态。
15. 延迟观测按采集时间处理；历史回退与重放不等于篡改时间戳，也不同于离线利用未来观测。
16. 参数扫描同时记录静止标准差、均值偏差和匀速等效滞后；标准差预算不是绝对定位误差上限。
17. 补充线性／非线性跟踪微分器及其导数估计取舍，依据 `1102.2599v2`；没有将某个连续模型的收敛结论扩展成所有实现的通用保证。
18. 补充协方差交集对未知相关性融合的用途，链接 Julier／Uhlmann 的 SLAM 论文；相同单位方差估计复制两份的例子只做解析说明，没有实现或比较分布式定位系统。
