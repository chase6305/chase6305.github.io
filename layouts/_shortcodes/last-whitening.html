动手看：白化为什么会改变最近码字

固定无量纲残差 r = (2, 0.2)，原坐标中的候选 A = (0, 0.2)、B = (2, 1.2)。原坐标欧氏距离恒为 2 和 1，选择 B。两候选与残差使用同一个白化矩阵；改变协方差的尺度比、主轴方向或正则项，观察白化距离的选择。

默认主轴标准差比 3∶1、方向 0°、正则项 0：白化距离 A = 0.6667、B = 1.0000，选择 A；正则化后协方差条件数为 9。A 的原坐标误差更大，但白化距离更小。

ρ 范围 1 到 10，θ 范围 0° 到 90°，ε 范围 0 到 10。协方差为 Q diag(ρ², 1) Qᵀ + εI，Q 为平面旋转。原协方差已正定，允许 ε = 0。结果保留四位小数。
