动手看：更强的先验会让错误结果更确定吗

构造真值 k = 0.2°、a = −0.1°。第一项观测偏置和 y₁ = k + a = 0.1°；第二项观测 y₂ = ε(k − a) = 0.3ε°，用 ε 调整独立激励。两项噪声独立、标准差均设为 0.02°；观测值取无噪声均值。膝关节采用均值 b、标准差 σₚ 的高斯先验。

默认 b = 0.4°、σₚ = 0.02°：估计 k = 0.4°、a = −0.3°，误差分别为 +0.2°、−0.2°；局部标准差为 0.0200°、0.0283°。数据矩阵的秩仍为 1；加入先验后总信息矩阵的秩为 2。

均值范围 −0.5° 到 0.5°，标准差范围 0.005° 到 0.3°，激励范围 0 到 1。ε = 0 时第二项没有参数信息；ε = 1 时两个数据方向等强。标准差越小，先验精度越高。结果保留四位小数。
