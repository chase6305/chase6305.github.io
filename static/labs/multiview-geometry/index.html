下载与 Python 复算

下载当前构造样本 JSON，再下载文章的 geometry_sanity.py，在同一目录运行：

python3 -B geometry_sanity.py \
  --input geometry-case.json

JSON 保存输入、图像网格、三种像素位置及未舍入结果。Python 从输入重新计算，不信任下载文件里已经写好的结果。
