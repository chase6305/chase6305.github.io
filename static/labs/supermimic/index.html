模型权重固定，策略梯度怎样通过？

改变策略输出、替代模型或中间状态的反向路径，比较预测轨迹、梯度与一次更新后的回报。

固定的一维问题：s₀ = 0，a₀ = a₁ = θ。参照转移为 s′ = s + 2a；替代转移为 s′ = s + ba + c。每步奖励 r = −(s′ − 1)²，目标是两步奖励之和。

参数 b、c 在策略更新中固定。梯度按链式法则显式计算，再用中心有限差分核对完整目标。这里取 γ = 1，省略观测噪声、终止、critic 和状态依赖的 actor；状态与动作没有指定物理单位。这些构造值用于核对计算，不是 G1 的动力学或论文实验结果。
