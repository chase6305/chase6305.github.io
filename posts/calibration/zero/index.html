零位标定能修正什么

关节零位偏置使编码器读数与模型中的关节角不一致。本文采用约定 qmodel=qencoder+ϕq_{\mathrm{model}}=q_{\mathrm{encoder}}+\phiqmodel​=qencoder​+ϕ，估计偏置 ϕ\phiϕ；写入控制器前必须核对厂商的符号、单位和补偿位置，避免软件和控制器重复补偿。

零位标定不能代替连杆几何、基座、工具或相机外参标定。模型误差也不能全部归因于编码器零点。

先用单关节看清偏置符号和误差量级

设一根长度 0.5 m 的平面连杆，编码器报告零角度，但真实几何角度为 +0.01+0.01+0.01 rad。采用本文“编码器加偏置”的约定，真实末端为 (0.5cos⁡0.01,0.5sin⁡0.01)(0.5\cos0.01,0.5\sin0.01)(0.5cos0.01,0.5sin0.01) m，而未补偿 FK 给出 (0.5,0)(0.5,0)(0.5,0) m。

两者的 y 向差约为 5 mm，x 向差约为 −0.025 mm。零位处的位置 Jacobian 为 [0,0.5]T[0,0.5]^T[0,0.5]T m/rad，一阶预测 Jϕ=[0,0.005]TJ\phi=[0,0.005]^TJϕ=[0,0.005]T m，能够解释主导的 y 向误差。x 向小量来自二阶项，因此初始误差较大时需要迭代重新线性化。

这个例子还说明，同样 0.01 rad 的角度偏置，在不同臂长和姿态下会表现成不同的位置误差；不能由“一次量到 5 mm”直接给所有关节减去同一个角度。符号应通过明确的 FK 和观测残差确定，控制器采用相反偏置定义时还需转换。

两种观测，不能混用

设 p(q)p(q)p(q) 为同一基坐标系下的 TCP 位置，Jp(q)∈R3×mJ_p(q)\in\mathbb R^{3\times m}Jp​(q)∈R3×m 为位置对关节角的 Jacobian。小偏置的一阶模型为：

p(qi+ϕ)≈p(qi)+Jp(qi)ϕ. p(q_i+\phi)\approx p(q_i)+J_p(q_i)\phi. p(qi​+ϕ)≈p(qi​)+Jp​(qi​)ϕ.

已知每次测量的 TCP 位置

若外部测量系统给出 pimeasp_i^{\mathrm{meas}}pimeas​，则堆叠：

Y=[p1meas−p(q1)⋮pnmeas−p(qn)],B=[Jp(q1)⋮Jp(qn)],Bϕ≈Y. Y=\begin{bmatrix}p_1^{\mathrm{meas}}-p(q_1)\\ \vdots\\p_n^{\mathrm{meas}}-p(q_n)\end{bmatrix}, \qquad B=\begin{bmatrix}J_p(q_1)\\ \vdots\\J_p(q_n)\end{bmatrix}, \qquad B\phi\approx Y. Y=​p1meas​−p(q1​)⋮pnmeas​−p(qn​)​​,B=​Jp​(q1​)⋮Jp​(qn​)​​,Bϕ≈Y.

测量值与 FK 必须使用同一坐标系、同一 TCP 定义及米/弧度等一致单位。

只知道多次触碰的是同一个未知点

固定点 PPP 未知时，不能凭空填入 p_real。可以通过与参考姿态作差消去 PPP：

[Jp(qi)−Jp(q1)]ϕ≈p(q1)−p(qi),i=2,…,n. [J_p(q_i)-J_p(q_1)]\phi \approx p(q_1)-p(q_i),\qquad i=2,\dots,n. [Jp​(qi​)−Jp​(q1​)]ϕ≈p(q1​)−p(qi​),i=2,…,n.

另一种方式是联合估计 ϕ\phiϕ 和 PPP，构造 [Jp(qi),−I][ϕ⊤,P⊤]⊤≈−p(qi)[J_p(q_i),-I][\phi^\top,P^\top]^\top\approx-p(q_i)[Jp​(qi​),−I][ϕ⊤,P⊤]⊤≈−p(qi​)。两种方式都需分析秩；差分会引入相关噪声，精密估计应使用合适的加权最小二乘。

用 SVD/QR 求解，不显式求逆

求解 min⁡ϕ∥Bϕ−Y∥22\min_\phi\|B\phi-Y\|_2^2minϕ​∥Bϕ−Y∥22​。不要把正规方程的显式逆作为默认实现，它会放大病态问题。以下是验证求解过程的合成数据，不是实测精度报告：

import numpy as np


def fk_and_jacobian(q):
    q = np.asarray(q, dtype=float)
    a, b = q[:, 0], q[:, 0] + q[:, 1]
    l1, l2 = 0.8, 0.6
    p = np.column_stack((l1 * np.cos(a) + l2 * np.cos(b),
                         l1 * np.sin(a) + l2 * np.sin(b)))
    first = np.column_stack((-l1 * np.sin(a) - l2 * np.sin(b),
                              l1 * np.cos(a) + l2 * np.cos(b)))
    second = np.column_stack((-l2 * np.sin(b), l2 * np.cos(b)))
    return p, np.stack((first, second), axis=-1)  # [N,2], [N,2,2]


rng = np.random.default_rng(42)
q_encoder = rng.uniform([-1.2, 0.3], [1.2, 2.3], size=(30, 2))
phi_true = np.array([0.018, -0.026])  # rad；仅用于合成数据
p_measured, _ = fk_and_jacobian(q_encoder + phi_true)
train = 20
phi = np.zeros(2)
for iteration in range(20):
    predicted, jacobian = fk_and_jacobian(q_encoder[:train] + phi)
    B = jacobian.reshape(-1, 2)
    Y = (p_measured[:train] - predicted).ravel()
    delta, _, rank, singular_values = np.linalg.lstsq(B, Y, rcond=None)
    if rank < B.shape[1]:
        raise ValueError("Unidentifiable offsets; change observations or model")
    phi += delta
    if np.linalg.norm(delta) < 1e-12:
        break
else:
    raise RuntimeError("Calibration iteration budget exceeded")

np.testing.assert_allclose(phi, phi_true, atol=1e-10)
validation, _ = fk_and_jacobian(q_encoder[train:] + phi)
errors = np.linalg.norm(validation - p_measured[train:], axis=1)
assert errors.max() < 1e-10
print("offset [rad]:", phi)
print("singular values:", singular_values)
print("held-out position error [m]:", errors.max())

上例是两连杆平面模型的已知位置观测，用 20 组姿态估计两个零偏，再用另外 10 组验证；每轮在更新后的 q+ϕq+\phiq+ϕ 处重新计算 FK 和 Jacobian。真实模型偏差较大或有噪声时，还需步长控制、鲁棒性与参数尺度检查，不能把无噪声示例的近机器精度容差直接作为实机门槛。

采样数量不等于可观测性

“采 20 个点”只是经验选择，不是保证。已知位置时，3n≥m3n\ge m3n≥m 只是必要的维度条件，真正需要的是 BBB 对待估参数满列秩，且最小奇异值不过小。未知点或附加工具参数会改变未知量数量。

尽量覆盖不同肘部形态、关节组合和末端姿态，避免只在相邻姿态重复采集。保留独立验证姿态，报告标定前后的均方根误差、最大误差及重复测量误差；训练残差下降不代表工作空间整体精度提高。

一个反例：触碰 40 次，也不能确定全部零位

考虑平面三转动关节机械臂，三根连杆长度为 0.8、0.6、0.4 m，用 40 种不同姿态触碰同一个未知点。基座坐标系固定，但固定点的坐标没有外部测量。

若第一关节的零偏整体增加 α\alphaα，所有 TCP 位置会绕基座旋转同样角度。把待估固定点也旋转 α\alphaα，每次“是否触碰同一点”的残差完全不变：

p(qi+ϕ+αe1)=R(α)p(qi+ϕ),P′=R(α)P. p(q_i+\phi+\alpha e_1)=R(\alpha)p(q_i+\phi),\qquad P'=R(\alpha)P. p(qi​+ϕ+αe1​)=R(α)p(qi​+ϕ),P′=R(α)P.

所以，仅靠这些接触条件，无法区分这一整族解。在线性化后的联合系统中，JpJ_pJp​ 第一列在接触姿态下都等于 [−Py,Px]⊤[-P_y,P_x]^\top[−Py​,Px​]⊤，于是存在零空间方向：

[Jp(qi)−I][100−PyPx] ⁣⊤=0. \begin{bmatrix}J_p(q_i)&-I\end{bmatrix} \begin{bmatrix}1&0&0&-P_y&P_x\end{bmatrix}^{\!\top}=0. [Jp​(qi​)​−I​][1​0​0​−Py​​Px​​]⊤=0.

对所有姿态作差时，第一列也会完全消失。这是观测模型缺少绝对方向基准，增加同类接触姿态不能消除它。这里是平面 3R 模型的具体反例，不是宣称所有空间机械臂都恰好缺少同一个参数；真实结构要重新建立观测 Jacobian。

留出接触姿态也可能共享同一个盲区

实验设置真实零偏为 [0.02, -0.03, 0.025] rad，固定第一零偏为 0 后，拟合得到 [0, -0.03, 0.025] rad，并把未知固定点旋转到另一个位置。另用 11 组未参与拟合的接触姿态检查：

  • 相对于拟合出的未知点，最大接触残差小于 1e-10 m。
  • 相对于外部已知的真实点，位置误差约为 0.02596 m，即 25.96 mm。

这些都是无噪声合成数据。第二个误差可独立用 2∥P∥sin⁡(∣0.02∣/2)2\|P\|\sin(|0.02|/2)2∥P∥sin(∣0.02∣/2) 复算；第一个极小残差只说明共同接触约束成立，没有验证绝对位置。留出数据必须对应真正关心的可观测量，否则换了一批姿态仍看不到同一个系统偏差。

脚本在精确接触解处计算秩，并验证有限角度旋转后残差仍为零。联合矩阵中角度与位置参数单位不同，因此原始奇异值只用来演示精确秩亏；比较实际可辨识程度前，还要按参数尺度归一化，见运动学标定中的尺度与可辨识性。

上机前检查

  • 离线验证偏置方向、角度单位、关节顺序和 TCP 定义。
  • 检查偏置是否合理，若异常大，先检查机械装配、模型和测量坐标变换。
  • 先在仿真或安全速度下验证关节限位、碰撞和急停，不直接将示例数值写入机器人。

阅读自测与验收

  • 在合成零位偏置上测试恢复误差，并比较已知参考点与未知支点两种模型；未知点坐标也要进入待估计变量或消元过程。
  • 检查奇异值、验证位姿残差和参数物理范围；只有总残差变小而没有独立验证，不足以说明零位参数可信。
